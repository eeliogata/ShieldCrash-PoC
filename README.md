# ShieldCrash

Build x64 with `make` or `ShieldCrash.slnx` in Visual Studio.

Run `.\ShieldCrash.exe C:\path\to\protected-file` as a standard user on Windows with Defender enabled. A successful run writes a GUID-suffixed copy beside the executable.

Original: [NightmareEclipse/ShieldCrash](https://git.projectnightcrawler.dev/NightmareEclipse/ShieldCrash).
